# Git Learning



Repositório para aprender Git e GitHub.



## Objetivos



- Aprender a criar commits

- Trabalhar com branches

- Utilizar Pull Requests

- Resolver conflitos

- Aprender boas práticas de versionamento



## Comandos Git



### Verificar o estado do repositório



`git status`



### Adicionar ficheiros



`git add README.md`



### Criar um commit



`git commit -m "Descrição da alteração"`



### Enviar alterações para o GitHub



`git push`
